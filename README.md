# 小黑盒论坛 - VSCode 插件 🎮

[![GitHub](https://img.shields.io/badge/GitHub-WenfuRainbow/heybox-blue?logo=github)](https://github.com/WenfuRainbow/heybox)

在 VSCode 中浏览小黑盒（xiaoheihe.cn）论坛帖子和评论，支持隐身模式。

## 功能

### 🔐 登录/退出登录
侧边栏工具栏提供登录和退出登录按钮：
- **扫码登录** — 点击登录后，用小黑盒 App 扫描二维码并在手机上确认；二维码在插件本地生成，登录凭证只保存到 VSCode SecretStorage
- **手动 Cookie（兼容兜底）** — 若扫码服务异常，可在扫码面板中选择“粘贴 Cookie”
- **退出登录** — 清除已保存的 Cookie

### 🎨 主题切换
支持手动切换 Webview 主题：
- **跟随 VSCode** — 自动匹配当前主题（默认）
- **暗色主题** — 强制使用暗色
- **亮色主题** — 强制使用亮色

### 📌 推荐 & 📁 板块 & ⭐ 收藏 & 🔔 消息（Tab 切换）
侧边栏顶部有 Tab 切换按钮：
- **推荐** — 热门推荐信息流
- **板块** — 论坛话题板块（数码硬件、盒友杂谈、Steam 等），点击展开帖子列表，支持"加载更多"分页
- **收藏** — 优先读取小黑盒服务端默认收藏夹，支持分页；读取失败时才回退显示本地旧缓存。右键帖子可收藏/取消收藏，完成后自动刷新云端列表
- **消息** — 按需展开“评论与回复、获赞、关注、@我、官方消息、游戏优惠”六类内容，均支持分页；互动消息可直接跳转关联帖子

### 🔍 搜索帖子
点击侧边栏顶部的 🔍 图标，输入关键词搜索全站帖子，搜索结果支持分页和"返回话题列表"。

### 📄 帖子详情
点击帖子在 Webview 中查看完整内容和评论（含图片、楼层、子评论嵌套）。正文中的图片会按照原帖富文本中的位置显示，不会统一追加到正文末尾；同时兼容小黑盒接口返回的 `data-original`、`data-src` 图片地址，并自动过滤重复图片。列表加载不会后台批量请求帖子详情，详情数据仅在用户主动打开帖子时加载，以减少触发服务端风控的概率。

每条首层评论会根据接口返回的 `child_num` 显示回复总数。点击“全部 N 条回复”可按需加载回复，已加载完成的回复不会重复显示；加载过程中会保留当前滚动位置和折叠评论提示。

支持三种显示位置，通过设置 `heybox.postDetailLocation` 切换：

| 选项 | 效果 |
|------|------|
| `sidebar`（默认） | 在侧边栏/面板区域显示（可拖到下方 Panel，VSCode 记住位置） |
| `editor` | 在编辑区打开全尺寸 Webview 面板 |
| `beside` | 在编辑区右侧分栏显示 |

### 🎭 隐身模式
开启后界面伪装为代码片段名称，适合办公环境使用。

设置项：`heybox.stealthMode: true`

- Webview 标题显示为 `README.md`
- 帖子作者和评论者头像隐藏
- 评论点赞数隐藏
- 无论帖子详情显示在哪个位置均生效

### 🌿 简约模式
隐藏收藏/评论等社交数据，帖子列表看起来更像代码文件列表。

设置项：`heybox.minimalMode: true`

### 🖼️ 图片大小控制
帖子详情顶部有图片大小拖动条（5%~100%），可统一缩放正文和评论中的图片。设置项持久化（localStorage）。滑动条固定在顶部，滚动帖子内容时始终可见。

### 🔍 图片悬停预览
鼠标悬停在帖子正文或评论的图片上时，在鼠标右侧显示原图大小的预览框（不受缩放滑块限制），方便查看图片细节。

### 🔔 消息通知
自动监控小黑盒互动消息（回复、点赞、关注、@我）、官方消息和已关注游戏的优惠消息。登录后自动开启，每 3 分钟检查一次；接口明确标为未读时才提醒。对未返回已读字段的类别，插件仅提醒启动后新到达的消息，历史消息只在列表中展示。

- 状态栏显示新消息数量，点击可关闭/开启通知
- 右键状态栏可查看已读状态说明；已读操作以小黑盒客户端的服务端状态为准

### ⌨️ 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Shift+J` | 切换侧边栏显示/隐藏 |
| `Alt+H` | 切换侧边栏（备选） |
| `Ctrl+Shift+Enter` | 从剪贴板 URL 自动打开帖子 |

## 安装

### 从 VSIX 安装
1. 下载 `.vsix` 文件
2. 在 VSCode 中按 `Ctrl+Shift+P` → `Extensions: Install from VSIX...`
3. 选择下载的 `.vsix` 文件

## 首次使用

1. 安装后在侧边栏出现 HeyBox 图标，点击展开侧边栏
2. 点击侧边栏工具栏的登录按钮
3. 使用手机上的小黑盒 App 扫描二维码，并在手机上确认登录

> ⚠️ 登录凭证会过期，过期后重新扫码登录即可。若二维码失效，点击“刷新二维码”重新生成。

如果打开帖子时遇到服务端风控提示，请等待限制解除后重试，或在浏览器中完成人机验证后重新复制 Cookie 并手动粘贴。插件当前不提供网页登录入口。

## 配置项

| 设置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `heybox.cookie` | string | `""` | 小黑盒网站 Cookie（通过登录命令设置） |
| `heybox.heyboxId` | string | `""` | 用户 ID（自动从 Cookie 提取） |
| `heybox.deviceId` | string | `""` | 设备 ID（自动生成） |
| `heybox.stealthMode` | boolean | `false` | 隐身模式 |
| `heybox.minimalMode` | boolean | `false` | 简约模式 |
| `heybox.postDetailLocation` | enum | `"sidebar"` | 帖子详情显示位置（sidebar/editor/beside） |
| `heybox.theme` | enum | `"auto"` | Webview 主题（auto/dark/light） |

## 开发

```bash
npm install      # 安装依赖
npm run compile  # 编译 TypeScript
F5               # 启动 Extension Development Host
```

## 隐私说明

- 插件仅通过 API 读取公开论坛数据
- 扫码二维码在本地生成；Cookie 仅存储在 VSCode SecretStorage 中（加密），不写入明文配置或 Webview
- 不会收集任何用户数据
